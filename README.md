# 🌸 OvaCare Pro

## AI-Powered Women's Health Ecosystem

OvaCare Pro is an AI-powered healthcare platform designed to support women through different stages of hormonal and reproductive health.

The platform provides personalized wellness guidance, symptom tracking, AI-powered recommendations, and health monitoring tools for:

- 🧬 PCOS / PCOD
- 🩸 Endometriosis
- 👶 Fertility Optimization
- 🍂 Menopause & Perimenopause

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/OvaCare-Pro.git
cd OvaCare-Pro
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Create .env File

```env
GROQ_API_KEY=your_api_key_here
```

### Run Application

```bash
streamlit run app.py
```
